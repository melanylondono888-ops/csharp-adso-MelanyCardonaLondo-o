### Comparación de Instrucciones: Python vs JavaScript vs C#

| Descripción | Python | JavaScript | C# |
| :--- | :--- | :--- | :--- |
| **1. Mostrar en pantalla** | `print("Hola")` | `console.log("Hola");` | `Console.WriteLine("Hola");` |
| **2. Leer datos del usuario** | `nombre = input()` | `prompt("Nombre");` | `string nombre = Console.ReadLine();` |
| **3. Declarar una variable** | `edad = 25` | `let edad = 25;` | `int edad = 25;` |
| **4. Condicional (Si / Si no)** | `if x > 5: ... else: ...` | `if (x > 5) { ... } else { ... }` | `if (x > 5) { ... } else { ... }` |
| **5. Bucle Repetitivo** | `for i in range(5):` | `for (let i = 0; i < 5; i++)` | `for (int i = 0; i < 5; i++)` |
| **6. Definir una función** | `def saludar():` | `function saludar() { }` | `void Saludar() { }` |
